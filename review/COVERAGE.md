# UI review coverage

Date: 2026-09-20. See [ranked findings and limitations](UI_REVIEW.md).

All 97 routes were opened at 2560×1440, 1920×1080, and 1280×720 CSS pixels. Screenshots capture the main content and previews; component reference tables are generally outside these crops. Visual inspection used contact sheets and targeted full-resolution screenshots. The component sweep covered 86 routes at each width (258 route/viewport runs). Counts below are logged control operations, not assertions that every workflow passed.

The sweep includes keyboard activation, editable fields, native choices, and Preview/HTML controls where present. Disabled controls were skipped; many links were inspected rather than followed. Dynamic branches, backend-owned actions, and every possible keyboard sequence were not exhaustively tested. Targeted follow-up flows are described in the report. Guides/foundations received visual review, not the component control sweep.

Raw logs: [viewport inventory](viewport-audit.json), [control sweep](interaction-audit.json), [targeted follow-ups](flow-audit.json). Early sweep logs contain documentation-tab selector ambiguities and overlay transition timing artifacts; these are harness limitations, not product defects. No-change entries may be intentionally static examples. Copy-button activation alone does not verify clipboard contents.
