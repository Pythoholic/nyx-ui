Accent is the single action color: primary buttons, active tabs, live price. Signal green marks healthy state and gains. Red for loss and destructive, blue and violet only as data-series colors. Tinted surfaces are built from the accent at 10% fill / 45% border, never a solid saturated block.

// 09 — THEMES

Accent themes

The surface system never changes: slate-black void, panels, lines and ink are fixed across every theme. A theme swaps five accent properties only. Signal green, danger red, info blue and alt violet keep their semantic meaning. Apply a theme structurally with data-nyx-theme="solar" on the root HTML element; components inherit the variables automatically.
